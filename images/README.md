# Imágenes
Sube aquí las fotografías de tus prendas, por ejemplo images/vestido-rosa.jpg, y configúralas en el panel demo usando su ruta.
Puedes sustituir images/logo.svg por tu logo definitivo o cambiar index.html para usar images/logo.png.
Las fotografías de ejemplo son imágenes remotas para mostrar el diseño; no son stock real ni prueba de disponibilidad.
