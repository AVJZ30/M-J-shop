# Favicons de M&J Shop
Esta carpeta ya incluye favicon.svg. Puedes subir aquí tus archivos adicionales:
- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- apple-touch-icon.png (180×180)
- android-chrome-192x192.png
- android-chrome-512x512.png
- site.webmanifest

Si subes iconos adicionales, agrega sus enlaces en el <head> de index.html.
El favicon.svg incluido es una recreación sencilla de las iniciales de la marca.
